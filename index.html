Importante: esta versión mejora mucho el comportamiento del prototipo, pero sigue usando OSRM + Nominatim + OpenStreetMap desde el navegador. La elevación continúa siendo una estimación, porque para tener desnivel real habría que conectar un servicio de datos topográficos/elevación. El siguiente salto que haría para una RIDER 3.0 sería bastante más potente: conectar un motor especializado de rutas y datos de elevación, de modo que RIDER pueda distinguir de verdad entre una carretera de curvas, una recta, un puerto de montaña, una secundaria escénica, etc., en vez de inferirlo únicamente de la geometría.
