Lo que cambia respecto a tu 2.1 La diferencia importante es que ahora RIDER ya no inventa el desnivel ni utiliza OSRM como motor principal: OpenRouteService calcula las rutas reales. Las rutas pueden llevar elevación y datos adicionales. RIDER analiza la geometría para obtener un índice de curvas. Se calcula un RIDER SCORE ponderando curvas, montaña, secundarias, paisaje y diversión. Las opciones de evitar autopistas y peajes se envían al motor. La ruta circular de hasta 100 km puede usar el modo round_trip de ORS; para distancias superiores he preparado una estrategia de waypoints porque la API pública limita las rutas alternativas/round-trip a 100 km. � openrouteservice.org Se generan varias alternativas y se ordenan por compatibilidad. La elevación viene del servicio de elevación/routing de ORS, que utiliza datos topográficos, en lugar de la estimación de las versiones anteriores. � openrouteservice.org +1 Primer paso para probarla: consigue tu API key desde el panel de openrouteservice y reemplaza: const ORS_API_KEY = "PON_AQUI_TU_API_KEY"; por tu clave.
